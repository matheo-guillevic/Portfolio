Présentation

RFIDEES vise à garantir une haute fiabilité de ses cartes électroniques. Pour ce faire, il est crucial de les tester efficacement et de disposer de protocoles précis. Actuellement, les tests fonctionnels sont automatisés. L’objectif de ce stage est d’automatiser le processus des tests climatiques à l’aide d’une étuve Binder puis le synchroniser avec l’acquisition de données sur les cartes. Le tout, permettant de tester efficacement la fiabilité des cartes. La première étape de cette mission consiste à comprendre le fonctionnement interne de la machine, analyser les communications possibles et les actions réalisables pour pouvoir la programmer à distance. Ensuite, il s’agit de développer une application à partir de zéro, en utilisant Windev, pour programmer la machine à distance et ainsi permettre l’automatisation des tests de fiabilité. Dans cette deuxième phase, il est nécessaire de concevoir une application ergonomique et fonctionnelle, qui sera ensuite intégrée à l’application de tests des cartes permettant l’exécution de scripts des tests sur les cartes. L’objectif final est de disposer d’une application globale capable de lancer des tests d’effort sur les cartes électroniques placées dans l’étuve et de générer un rapport attestant de leur fiabilité.

Difficultés et réussites

La difficulté résidait dans la prise en main et la compréhension de l'étuve Binder, car je partais de zéro sans connaître la machine ni le protocole de communication utilisé. J'ai réussi à mener à bien les recherches nécessaires pour découvrir progressivement les informations requises pour accomplir cette mission.
